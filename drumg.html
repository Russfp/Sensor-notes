How This Drum Machine Synthesizes Sound

This application does not rely on external .wav or .mp3 files. Every sound is generated programmatically in real time using the native Web Audio API.

1. The Kick Drum (Sine Wave + Pitch Drop)

A kick drum is created using a sine wave oscillator. The pitch starts high (~150 Hz) and rapidly drops to a low frequency (~0.01 Hz) within milliseconds. Simultaneously, the volume decays quickly to simulate the thud of a physical drumhead.

osc.frequency.setValueAtTime(150, time);
osc.frequency.exponentialRampToValueAtTime(0.01, time + 0.5);

2. The Hi-Hat (Filtered White Noise)

A hi-hat has no distinct musical pitch. It is created by generating white noise (random audio buffer values) and running it through a High-Pass Filter to cut out low/mid frequencies, leaving only crisp, metallic highs with a very short decay.

filter.type = 'highpass';
filter.frequency.value = 7000; // Only allows frequencies above 7kHz

3. The Snare Drum (Tone + Noise)

A snare combines two elements: a mid-frequency sine wave pitch (representing the drum body) and a burst of white noise passed through a high-pass filter (representing the snare wires rattling against the bottom head).

4. The Sequencer Loop

To keep accurate time without drifting, Web Audio applications use AudioContext.currentTime for precise hardware-level audio scheduling rather than standard JavaScript setInterval(), which can stutter due to browser rendering loads.
